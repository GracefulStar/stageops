# Что проверено

Этот файл фиксирует фактически выполненные проверки, а не только наличие тестов в репозитории.

## Python

Выполнен набор `backend/tests` без маркера `postgres`: **31 тест прошёл, 2 конкурентных теста исключены**.

- 12 проверок правил и валидации без SQL-базы.
- 19 интеграционных проверок FastAPI: каталог, даты, распределение, недостающее количество, повторные запросы, смена часового пояса базы, изоляция сценариев, некорректные данные, ограничение размера запроса, откат транзакции и прямое нарушение ограничения пересечения.
- Применена настоящая SQL-миграция Alembic; проверены SQL-запросы и ограничения.
- Через ASGI проверена отдача интерфейса, страницы оператора, изображения, `/docs`, OpenAPI и `/healthz`.
- `ruff check backend` и проверка форматирования проходят.

**Ограничение среды:** здесь нет доступного обычного сервера PostgreSQL и Docker. SQL-проверки выполнены с [PGlite](https://pglite.dev/), PostgreSQL в WebAssembly, с расширением `btree_gist` и официальным socket-мостом. Из-за особенностей его общего соединения тестовый адаптер отключал именованные prepared statements и использовал `psycopg.ClientCursor`. Производственный код и SQL-схема не заменялись SQLite или mock-объектами.

Это полезная проверка SQL и транзакционной логики, но **не** доказательство корректной работы конкурентных подключений обычной PostgreSQL. Для этого отдельно оставлены два теста с маркером `postgres`: два разных одновременных заказа и две одновременные отправки одного запроса. Полный набор подготовлен для PostgreSQL 16 в GitHub Actions, но запуск этого CI здесь не выполнялся.

Зависимость Starlette сообщает предупреждения об устаревающих API httpx/AnyIO. На результат выполненных тестов это не повлияло; предупреждения не скрывались.

## Интерфейс и текущий прототип

- Отдельная сборка интерфейса для Python: `npm run build:frontend` проходит.
- TypeScript: `npx tsc --noEmit` проходит.
- Сборка опубликованного прототипа проходит.
- 11 тестов прежнего SQL-движка на SQLite проходят.
- HTTP-проверка собранного Worker подтверждает работу клиентской страницы, отдельного оператора, изображений, заказа, повторной отправки, дефицита, запрета текущего месяца и изоляции сценариев.
- Проверка Python-прокси подтверждает пересылку четырёх маршрутов, JSON и cookies, ограничение тела запроса, отклонение перенаправлений и отсутствие переключения записи в D1 при ошибке Python.

Браузерная визуальная проверка в этой итерации не проводилась. Это не новый дизайн: используется существующий общий компонент интерфейса.

## Размещение

Dockerfile и Compose подготовлены; YAML проверен, но контейнеры здесь не запускались. Перед публичным переключением требуются полный прогон на PostgreSQL 16 и запуск контейнера на выбранном хостинге.

Текущая публичная ссылка пока использует TypeScript/D1. Python-проект не заявляется уже размещённым сервером. Подключение описано в `docs/deployment.md`.
